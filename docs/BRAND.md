# Brand assets

Source files supplied by the owner: the **official logo** (transparent PNG; gold XL monogram, black wordmark) and the **brand render** (the same logo embossed on a black card, silver wordmark).

The site is dark (black, antique gold, brushed silver). The official logo's wordmark is black, so it disappears on a dark page. The dark-background files below therefore pair the official gold monogram with the silver wordmark from the brand render. Nothing was redrawn: both parts are the owner's own pixels.

| File | Use |
| --- | --- |
| `public/brand/logo-dark.webp` | Full lockup (monogram + silver wordmark) for dark backgrounds: footer, admin sign-in |
| `public/brand/mark.webp` | Gold XL monogram only: site header, admin nav |
| `public/brand/brand-card.jpg` | The embossed black-card render, cropped: home-page hero |
| `public/brand/logo-official.png` | The official logo exactly as supplied (black wordmark), trimmed. For **light** backgrounds: documents, invoices, print |
| `src/app/icon.png`, `src/app/apple-icon.png` | Favicon and phone home-screen icon (monogram on near-black) |
| `src/app/opengraph-image.png` | Link preview when the site is shared (1200 × 630) |

Colors (in `src/app/globals.css`): background `#0b0b0d`, gold `#d9a441` (gradient `#f0c55b` to `#b5791f`), silver `#f4f5f7` to `#9a9ca4`, text `#f3efe6`.

A vector (SVG) version of the logo would make the header and favicon crisper at every size. If one exists, send it and swap it in.
